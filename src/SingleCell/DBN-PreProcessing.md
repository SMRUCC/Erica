经过伪时间排序之后的样本数据可以直接用于动态贝叶斯网络（DBN）建模，但伪时间不等于真实时间序列，直接把每个细胞当成一个时间点送入 DBN 会违反模型的核心假设，必须先做分箱/滑动窗口平滑、离散化等预处理，并强烈建议叠加 RNA velocity 提供的因果方向先验，否则推断出的边大概率是相关性而非因果性。
## 一、可行性：伪时间可作为发育顺序的近似时间轴
单细胞数据的本质是"快照"——每个细胞被测一次，无法直接观测其时间演化。轨迹推断（trajectory inference）方法（Monocle、Slingshot、PAGA、Diffusion Pseudotime、scVelo latent time 等）通过对表达谱相似性建模，把细胞排列到一条连续轨迹上，每个细胞被赋予一个伪时间值，表示其在动态过程（分化、发育、应激响应等）中的相对进度。PseudoGRN、SINGE、SINCERITIES、LEAP、Normi、scTIGER 等一系列方法已经把"伪时间排序后的表达序列"作为时间序列输入来推断有向基因调控网络（GRN），其中包括 DBN、时间滞后互信息、Granger 因果等多种建模范式。因此，把伪时间序列用作 DBN 的"时间轴"在文献中已有先例和可行性。
但需要明确一个关键概念：伪时间是"细胞分化状态/成熟度的度量，而非真实时间"（"the pseudotime coordinate ... should be interpreted as a measure of cellular differentiation state, or maturity, rather than one of real time"）。它捕捉的是状态空间的拓扑顺序，而非物理时间间隔。
## 二、需要警惕的假设不匹配
DBN 通常假设：**离散化、等间隔的时间点、一阶或有限阶马尔可夫性、单条线性时间轴、平稳随机过程**。把伪时间直接当成时间序列送入 DBN，至少会在以下几个方面与之冲突：
| 不匹配点 | 伪时间的实际情况 | 对 DBN 的影响 |
|---|---|---|
| 时间间隔 | 相邻细胞伪时间差值极不均匀，密度高的区段相邻间隔趋近 0，稀疏区段间隔很大 | 违反 DBN 等间隔假设，转移概率被密度噪声主导 |
| 样本独立性 | 细胞之间通过 KNN/MST 互相连接，相邻细胞高度相似 | 严重自相关，DBN 的独立样本假设失效，假阳性暴增 |
| 数据量与噪声 | 单细胞稀疏、dropout 严重、零膨胀 | 离散化后状态估计不稳，转移矩阵不可靠 |
| 轨迹拓扑 | 分叉、多分支、环状、收敛 DAG 等结构常见，单条线性序只是其中一种简化 | 把多条分支强行串成一条时间轴会引入虚假的跨分支转移 |
| 方向性 | 伪时间方向由人为指定根细胞，未必与真实发育方向一致 | DBN 学到的"未来→过去"边方向可能整体倒置 |
| 离散化需求 | DBN 多要求离散节点状态 | 单细胞表达连续且噪声大，简单二值化会丢失激活/抑制的中间态 |
此外，Normi 等方法让最优时间滞后大于一阶，PseudoGRN 等指出这"往往与生物学证据不一致"，多数研究支持一阶马尔可夫性——这恰好与 DBN 的一阶转移假设相容。
## 三、推荐的改造流程
将伪时间序列改造成符合 DBN 假设的时间序列，建议按以下流水线：
**步骤 1：基因预筛选**
对全基因组跑 DBN 在样本量上不可行。先基于伪时间上的差异表达检验、轨迹变化基因（如 scTrends 分类）或先验 TF 列表筛选 50–300 个目标基因，剔除零方差、dropout 率过高的基因。
**步骤 2：分箱/滑动窗口聚合**
这是最关键的一步。PseudoGRN、Normi、scTrends、SINGE 等都采用了"沿伪时间分箱或滑动窗口求均值"的策略来构造代表性"伪时间点"，从而消除密度不均和随机波动。具体做法：把伪时间区间等分为 K 个互不重叠的 bin（或宽度 w、步长 1 的滑动窗口），对落入每个 bin 的细胞求基因表达均值/中位数，得到 K×G 的"伪时间序列矩阵"。K 的选择需要在分辨率与统计稳定性间权衡，常见 20–100。
**步骤 3：表达值离散化或标准化**
- 若用经典离散 DBN：用分位数或 scBoolSeq 等方法把每个基因的表达二值化/三值化（低/中/高）。scBoolSeq 专门建立了从 scRNA-seq 统计特征到布尔激活状态的桥梁，可处理 dropout。
- 若用连续 DBN（如高斯/非参数回归 DBN）：可对每基因做 z-score 标准化，或用 splines 拟合后取残差。
**步骤 4：补充 RNA velocity 因果先验**
scVelo 的 latent time 基于剪接动力学给出有向信息，可作为伪时间方向和因果边的先验约束；RegVelo/SDEvelo 等进一步把调控先验整合进动力学模型。把 velocity 给出的高置信有向边作为 DBN 结构学习的"白名单"，可显著降低搜索空间、提升因果发现可靠性。
**步骤 5：分支结构处理**
对多分支轨迹，应对**每个分支单独**构造一条伪时间序列再分别建模，或采用树结构 DBN/时变 DBN（TV-DBN），而不是把不同分支的细胞合并排序。合并多分支会人为制造"细胞从 A 分支跳到 B 分支"的虚假转移。
**步骤 6：DBN 学习与验证**
对构造好的 K 个时间点 × G 个基因的矩阵，用 Banjo、bnlearn（R）、CGBayesNets 等做结构学习；时间滞后设为一阶；用 bootstrap 重采样评估边的稳定性；最后用文献/ChIP-seq/敲除数据等外部证据验证推断的边。
## 四、可直接采用的工具
如果不想自己造轮子，下面这些工具专门为"伪时间 → 调控网络"做了适配，多数内部即使用了 DBN 或等价的时间滞后模型：
- **SINGE**：基于 Granger 因果集成，专为不规则伪时间分布设计，对平滑后的伪时间序列做因果推断。
- **SINCERITIES**：基于伪时间排序的表达变化做 GRN 推断。
- **SCNS（Single Cell Network Synthesis）**：从伪时间排序的单细胞数据重建可执行 Boolean 网络，结合部分相关先验。
- **CellNOptC**：逻辑模型框架，可与 SCNS 配合做约束优化。
- **scBoolSeq**：把 scRNA-seq 二值化到 Boolean 状态，可直接喂给 Boolean/DBN 学习器。
- **PseudoGRN**：整合多种伪时间方法 + 时间滞后 f-散度/IPM + 非冗余惩罚 + 偏相关，输出有向符号网络。
- **LEAP**：基于滞后的相关分析，伪时间序列专用。
- **pGRN**：R 包，基于伪时间推断并可视化 GRN。
- **Velorama / SINGE**：结合 RNA velocity 的时序 GRN 推断。
## 五、常见误区与规避
- **直接用细胞级原始排序跑 DBN**：样本数巨大但高度自相关，假阳性率失控，且细胞间隔不均。必须先聚合到 bin。
- **忽视分箱等间隔化**：分箱时若按细胞数均分而非伪时间值均分，会导致密度高的区段被过度采样，时间间隔仍不均匀。
- **多分支强行合并成一条线性序**：会引入跨分支的虚假时间转移。应分线建树或用树结构模型。
- **缺少方向先验**：仅靠伪时间方向的 DBN 容易把方向学反；强烈建议用 RNA velocity 的 latent time 校验根细胞方向，并把 velocity 边作为白名单。
- **忽视 dropout 与零膨胀**：直接离散化会把"未检测到"误判为"低表达"，scBoolSeq 等工具可缓解。
- **把伪时间当作真实时间单位（小时/天）**：所有转移概率、延迟系数只反映状态推进，不可与实验真实时间换算。
- **样本量过小却不做 bootstrap**：K 通常只有几十，结构学习方差大，必须重采样评估稳定性。
## 六、落地建议
可行的最小流程：选 100 个候选基因 → Slingshot 或 scVelo latent time 排序 → 等宽度分 30–50 个 bin 取均值 → scBoolSeq 二值化 → bnlearn 跑一阶 DBN + bootstrap → 用 scVelo velocity 边作为白名单过滤 → 与 ChIP-seq/KEGG 比对验证。对单条线性轨迹这一流程可行；若轨迹分叉，请按分支分别建模或改用 SCNS/CellNOptC 这类原生支持树结构的工具。
