make_sample {GRN} R Documentation

Description

Usage

make_sample(monocle3, dbn.sample, hvgenes,
    method = "bins",
    num.bins = 30,
    window.size = 5,
    step = 1,
    gene.selection = "top",
    top.gene.fraction = 0.3,
    velocity.thres = NaN,
    discretize = FALSE,
    num.levels = 3,
    groupBy = NULL);

Arguments

monocle3

[as Monocle3Result]

dbn.sample

[as NumericMatrix]

hvgenes

-

method

分箱模式："bins"（等宽分箱，默认）或 "sliding"（滑动窗口）。. [as string]

num.bins

等宽分箱数量（method="bins" 时有效）。默认 30。. [as integer]

window.size

滑动窗口宽度（method="sliding" 时有效）。默认 5。. [as integer]

step

滑动窗口步长（method="sliding" 时有效）。默认 1。. [as integer]

gene.selection

基因筛选方式："top"（取速度幅度最高的 topGeneFraction 比例）或 "threshold"（速度幅度 > velocityThreshold）。默认 "top"。. [as string]

top.gene.fraction

top 模式下保留的基因比例（0~1）。默认 0.3。. [as double]

velocity.thres

threshold 模式的绝对阈值；设为 NaN 时自动取速度幅度中位数 × 2。. [as double]

discretize

是否对 bin 表达矩阵做分位数离散化（供离散 DBN）。默认 False。. [as boolean]

num.levels

离散化等级数（discretize=True 时有效）。默认 3。. [as integer]

groupBy

分支标签（每细胞所属 group）；为 Nothing 时按整体单轨迹分箱。预留（本次不启用分支）。. [as integer]
