getBetaTheta {STdeconvolve} R Documentation

get deconvolve result matrix

Description

<br /> Pull out cell-type proportions across pixels (theta) and<br /> cell-type gene probabilities (beta) matrices from fitted <br /> LDA models from fitLDA

Usage

getBetaTheta(LDA, corpus,
    top.genes = 25);

Arguments

LDA

an LDA model from topicmodels. [as LdaGibbsSampler]

corpus

[as STCorpus]

top.genes

[as integer]

Details

Authors

Erica

Value

A Deconvolve object that contains

  • beta: cell-type (rows) by gene (columns) distribution matrix. Each row is a probability distribution of a cell-type expressing each gene in the corpus.

  • theta: pixel (rows) by cell-types (columns) distribution matrix. Each row is the cell-type composition for a given pixel.

clr value class

  • Deconvolve
