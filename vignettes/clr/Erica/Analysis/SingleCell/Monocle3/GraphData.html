GraphData

Description

轻量级、可 JSON 序列化的无向加权图结构，用于在 Monocle3 各步骤之间 缓存图数据（KNN 图、MST 主图、PAGA 图等）。运行时再按需转换为 NetworkGraph(Of Integer) 供 Louvain / PAGA / Dijkstra 使用。

Declare

            
# namespace Erica.Analysis.SingleCell.Monocle3
export class GraphData {
   # 边表：u、v 为节点索引（对应 GraphData.nodes 下标），weight 为权重。
   edges: EdgeData[];
   # 节点标签（字符串 id）。索引隐含节点编号。
   nodes: string;
}
